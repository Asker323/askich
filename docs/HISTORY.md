# Исторические предметы

Карточки используют названия типов и музейные атрибуции, а не вымышленные «легендарные» имена. Игровые предметы не являются подлинными музейными экспонатами. Даты относятся к прототипам. Бонусы, выпадение добычи и разделение наборов по сторонам — игровые правила; они не означают, что другие народы не использовали подобное снаряжение.

- **Русь:** копьё с треугольным наконечником — [карточка музея «Куликово поле»](https://ar.culture.ru/ru/subject/nakonechnik-kopya-xiv-v), тип XII–XV вв.; кольчуга — [предмет XIII века из Брянского краеведческого музея](https://ar.culture.ru/ru/subject/kolchuga-27); шлем по образцу Ярослава Всеволодовича — [Музеи Московского Кремля](https://vision.kreml.ru/en-Us/about-museums/museum-collection/arms-and-armour/), XII–XIII вв.
- **Франция:** меч с дисковидным навершием — [Metropolitan Museum, 25.188.12](https://www.metmuseum.org/art/collection/search/32782), XIII век. Хауберк (hauberk) и кольчужный капюшон (coif) — по [исследованию надгробия Жана д’Аллюи, Metropolitan Museum Journal](https://resources.metmuseum.org/resources/metpublications/pdf/A_Crusaders_Sword_The_Metropolitan_Museum_Journal_v_26_1991.pdf). В изображённом доспехе капюшон соединён с рубахой; раздельные игровые слоты условны.
- **Норвегия:** топор и кольчуга по находкам из Гьермундбю — [каталог VÍKINGR, Исторический музей Осло](https://www.historiskmuseum.no/english/exhibitions/undermappe-utstillinger/handout-vikingr-web-engelsk.pdf), X век. Шлем по образцу Гьермундбю — [Музей эпохи викингов](https://www.vikingtidsmuseet.no/english/viking-age/power-and-weapons/the-gjermundbu-helmet.html), 950–975 гг. В игре это более раннее наследие, а не новое оружие XIII века.

Это первые девять предметов, по одному на каждый из трёх слотов каждой стороны. Подбор — E возле ящика на поле боя. Открытые предметы остаются в арсенале после поражения. Экипировка выбирается в главном меню; бонусы применяются при следующем начале похода. Предметы пока не заменяют отдельные части спрайта героя.

# Поселение и исторические условности

Жилища имеют три визуальные ступени с мотивами деревянного зодчества Руси, французских каркасных домов и норвежских деревянных построек. Это художественная стилизация, а не точные датированные реконструкции. Хозяйственные здания с версии 2.3 используют отдельный атлас из восьми типов, общий для сторон, с дополнительными рабочими местами и запасами при улучшении. Их культурные варианты и точная датированная реконструкция пока не реализованы.

Формы власти и устройства — упрощённая игровая модель. Термины «унитарное государство», «конфедерация» и «диктатура» не приписываются конкретным историческим государствам сюжета. Вече в игре не отождествляется с современной всеобщей демократией.
