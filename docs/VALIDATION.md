# Проверка GOIDA 2.3.0

29 октября 2026, Windows x64, Unity 6000.3.4f1.

- **44 интеграционных сценария прошли:** прежний бой, прогресс и перенос сохранений; восемь новых зданий; торговля партиями, запрет частичного списания и переполнения; отмена стройки без повторного возврата и потери прежнего уровня. [Отчёт](runtime-tests.json).
- Начальный путь к двору II по-прежнему проверяется за 900 моделируемых секунд без добавления ресурсов.
- **Реальные клики мышью** в отдельном диагностическом Windows-player: открытие поселения, пауза, вкладка хозяйства, партия из пяти поставок, обмен 150 дерева на 100 руды, блокировка покупки без средств, начало и отмена дома с точным возвратом, перенос существующего дома с сохранением вместимости. [Наблюдения и ограничения](ui-check.json).
- Для проверки мышью профиль подготовлен обычными командами экономики. Пользовательское сохранение не открывалось. Навигация и перечисленные действия затем выполнялись через настоящий оконный ввод, без программного вызова кнопок игры.
- Визуальный сценарий экономики достиг дня 111, двора III, конфедерации, вече и победного набега. Он дополнительно показал хозяйство, партию руды, событие купца и стройку. [Отчёт](settlement-playtest.json).
- Окончательный release: **Succeeded, 0 ошибок и 0 предупреждений, Development=False**. [Отчёт Unity](build-report.txt). Диагностические классы, включая ManualVillageCheck, исключены из release DLL.
- Скриншоты поселения, хозяйства и стройки получены в настоящем Windows-player. Надпись Development Build сохранена. После проверки мышью изменены только подписи паузы и количества поставок; окончательные кадры проверены повторно.

Боевая модель в 2.3 не менялась. Полный поход из [проверенного выпуска 2.2](https://github.com/Asker323/askich/blob/v2.2.0/docs/VALIDATION.md) завершился победой в пяти заданиях; текущий playtest.json относится именно к этому прогону. Скриншоты похода сохранены из 2.2, скриншоты поселения обновлены до 2.3. Интеграционные проверки боя повторены с новым кодом.

Служебный шейдер Hidden/Internal-Colored по-прежнему исключён и проверяется сборщиком. Новые изображения используют обычный Sprites/Default; отдельные неподдерживаемые шейдеры не добавлялись.

## Границы выпуска

**Android:** мультитач и мобильная раскладка проверены на Windows. APK не собран, физический телефон не тестировался: в Unity отсутствуют Android Build Support, SDK/NDK и OpenJDK. Частота кадров на Android не измерялась.

Новые полные анимации пока только у дружинника. Части исторической экипировки пока не заменяют спрайт. У мастерских теперь есть восемь собственных изображений, но они общие для стран; отдельные культурные и уровневые атласы ещё нужны. Набеги остаются расчётными офлайн-столкновениями. Подробности — в [плане следующих этапов](ROADMAP.md).

Поселения, экипировка, валюта, косметика и настройки сохраняются. Текущий поход между запусками не сохраняется. Длительный человеческий плейтест и проверка на другом ПК пока не проводились.

Обычный release EXE 2.3 также открыт и проверен через окно: версия в главном меню совпадает, сохранён прежний кошелёк, надписи Development Build нет. Выход выполнен кнопкой игры.
