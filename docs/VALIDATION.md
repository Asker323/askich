# Проверка Askich 2.1.0

Дата проверки: 28 октября 2026. Unity 6000.3.4f1, Windows x64.

- Release-сборка: **Succeeded, 0 ошибок, 0 предупреждений**, Development=False. [Отчёт Unity](build-report.txt).
- **32 интеграционных сценариев прошли.** Ближний бой, направленный щит, выносливость, миссии, выбор союзника, покупки, перенос профиля, историческая экипировка, строительство, экономика, реформы, набеги и сохранение отдельных поселений. [Отчёт](runtime-tests.json).
- Достижимость позднего развития проверяется обычными командами экономики без добавления ресурсов. Отдельный визуальный сценарий доходит до двора III, конфедерации, вече и победного набега. Навигация этого сценария программная, а не проверка мыши. [Отчёт поселения](settlement-playtest.json).
- Полный боевой прогон использует виртуальные клавиатуру и мышь внутри процесса игры с обычными характеристиками. Он не телепортирует героя и не меняет здоровье или врагов. [Отчёт похода](playtest.json).
- Скриншоты сделаны в диагностическом Windows-player, поэтому на них есть надпись Development Build. Релиз не содержит классы тестов и автопрохождения.

`Hidden/Internal-Colored` отсутствует в Always Included Shaders; сборщик отдельно проверяет это условие. Для спрайтов и интерфейса используются штатные поддерживаемые шейдеры.

## Границы проверки

Полный автоматический поход выполнен за дружинника; параметры всех трёх героев проверены интеграционно. Ручной баланс всех сторон ещё требует игровых отзывов. Сетевой игры нет. Набеги поселения — расчётные столкновения с анимацией. Исторические предметы влияют на характеристики, но не меняют отдельные части спрайта. Только жилища имеют отдельные культурные варианты каждого уровня; хозяйственные объекты используют общие спрайты с дополнительным декором.

Текущий поход не сохраняется между запусками. Поселения, экипировка, валюта, косметика и рекорды сохраняются локально. Независимая проверка на других компьютерах Windows не проводилась.

Android: проверены логика одновременных касаний и мобильная раскладка на Windows. APK не экспортирован из-за отсутствующих модулей Unity; телефон не тестировался. См. [ANDROID.md](ANDROID.md).

Один дополнительный прогон закончился корректным поражением после потери обоза: [отчёт](escort-failure-playtest.json). Приоритеты автопилота для защиты целей уточнены; это изменение диагностического сценария, а не боевого баланса.


Проверено содержимое release Assembly-CSharp.dll: ArenaGame присутствует, ArenaSmokeTests, ArenaPreview и SettlementPreview отсутствуют.

Итоговый боевой прогон: Victory, 5 заданий, 70 противников, 169,7 секунды, 100 здоровья в финале, список runtime errors пуст.
