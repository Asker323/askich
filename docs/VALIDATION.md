# Проверка GOIDA 2.4.0

29 октября 2026, Unity 6000.3.4f1.

## Windows

- **50 интеграционных сценариев прошли.** Бой, экономика, миграция профиля, отмена стройки и торговля; новые проверки однократного нажатия, отменённого жеста, ползунка, безопасной области и ухода в фон. [Отчёт](runtime-tests.json).
- **16 сценариев через виртуальный Touchscreen прошли в настоящем Windows-player.** Настройки и громкость, поселение, выбор участка, постройка и возврат ресурсов, хозяйство, выбор фракции, запуск боя, два одновременных пальца, остановка управления при отпускании, пауза и продолжение. [Отчёт](touch-playtest.json). События подаются в Input System и проходят Update/OnGUI; кнопки не вызываются напрямую. Использован отдельный временный профиль, ресурсы не добавлялись.
- Финальная Windows-сборка: **Succeeded, 0 ошибок, 0 предупреждений, Development=False**, Direct3D 11. [Отчёт Unity](build-report.txt).
- Обычный release EXE запущен: главное меню показывает 2.4.0, прежний кошелёк сохранён, настройки открываются настоящим кликом мыши, надписи Development Build нет.
- Путь к двору II за 900 моделируемых секунд проверяется прежним интеграционным сценарием; это не замер времени реального игрока.

Скриншоты mobile-settings.png, mobile-construction.png и touch-controls.png — реальные кадры диагностического Windows-player 2.4 с виртуальным сенсорным вводом. Это **не кадры Android**. Настройки на них показывают предел кадров Windows. Изображения старых разделов сохраняют происхождение из 2.2/2.3.

Полный поход последовательно пройден в [2.2](https://github.com/Asker323/askich/blob/v2.2.0/docs/VALIDATION.md), полный сценарий торговли и переноса настоящей мышью — в [2.3](https://github.com/Asker323/askich/blob/v2.3.0/docs/VALIDATION.md). Файлы playtest.json, settlement-playtest.json и ui-check.json сохранены как свидетельства этих предыдущих этапов; они не объявлены повторными прогонами 2.4. Проверки логики боя и экономики повторены в текущей сборке.

Служебный Hidden/Internal-Colored исключён и проверяется сборщиком. Диагностические сценарии компилируются только для редактора и Development Build.

## Android и ограничения

Статус экспорта, подписи и проверки APK указан в [ANDROID.md](ANDROID.md). **Физический телефон не тестировался**, производительность, нагрев и читаемость на маленьком экране не измерялись. Автоматическая пауза проверена вызовом обработчика в Windows, а не реальным сворачиванием Android-приложения.

Сохраняются поселения, снаряжение, валюта, косметика и настройки. Текущий поход не сохраняется между запусками и не восстанавливается после выгрузки приложения системой. Формат профиля не менялся.

Полные новые анимации пока только у дружинника, историческая экипировка пока не заменяет видимые части героя. Мастерские общие для культур. Набеги остаются расчётными офлайн-столкновениями. [Следующие этапы](ROADMAP.md).
