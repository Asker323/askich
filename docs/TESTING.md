# Проверка Askich

## Сборка и правила боя

`Askich.Editor.BuildGame.Windows` перед созданием Windows player проверяет:

- допустимые номера волн и количество врагов;
- ограничение движения границами арены с учётом радиуса;
- попадание быстрого снаряда, касание, промах и вырожденную траекторию;
- ровно один `ArenaGame` в стартовой сцене и отсутствие потерянных скриптов.

Запускай сборку через **Askich → Build Windows** или команду из README. Для development player установи `ASKICH_DEVELOPMENT=1` и отдельный `ASKICH_BUILD_DIR`.

## Сценарии игры

Для автоматического набора запусти диагностический `Askich.exe` с аргументами:

```text
-batchmode -nographics -askich-smoke -askich-test-output <абсолютный-путь-к-results.json>
```

Набор возвращает код `0` при успехе, пишет JSON и маркер `ASKICH_SMOKE_PASS`. Чтобы воспроизвести игровой прогон и скриншоты, запусти диагностический player с видимым окном:

```text
-askich-preview -askich-preview-output <абсолютный-путь-к-папке>
```

Обычная release-сборка не содержит этих компонентов. Прогон не записывает личный профиль.

Ручные сценарии:

1. Запусти release player и проверь меню, название Askich и версию.
2. Начни новую игру: прочитай вступление и перейди к первой волне.
3. Проверь WASD, стрелки, прицеливание, удержание огня, рывок, паузу и звук.
4. Подбери кредитный осколок; проверь изменение кошелька и сохранение суммы после перезапуска приложения.
5. Получи урон и доведи забег до поражения. Собранные кредиты должны сохраниться, а боевые улучшения — сброситься при новом забеге.
6. Заверши волну: проверь бонус кредитов, сюжетную сцену и выбор одного из трёх улучшений.
7. После второй волны проверь обе ветки сюжета в отдельных забегах: сохранение архива и подавление маяка.
8. Проверь переход с «Холодного причала» в «Живую кузницу» на третьей волне.
9. В ангаре попробуй купить скин при недостаточном балансе, затем при достаточном. Списание должно происходить один раз.
10. Экипируй каждый купленный скин и перезапусти приложение. Внешность должна сохраниться; боевые характеристики не должны изменяться.
11. Заверши пятую волну и проверь соответствующий сюжетному выбору финал.
12. Сделай скриншот F12, проверь читаемость HUD и масштабирование при изменении размера окна.

## Сохранения и тестовая изоляция

Автоматические проверки профиля должны использовать отдельный временный каталог через предусмотренный кодом override пути сохранения. Они не должны изменять настоящий кошелёк, купленные скины или выбранный облик игрока.

Проверки перехода к победе с принудительным завершением волн следует отмечать отдельно от ручного прохождения всех боёв. Проверка сохранений, экономики и веток сюжета не подтверждает баланс сложности.

Фактический статус находится в [VALIDATION.md](VALIDATION.md).
