# Выбор контейнера и обыск мышью

Локальный этап для Windows, 7 ноября 2026. Unity 6000.3.4f1.

## Что изменилось

- Доступный контейнер отмечается тонкой рамкой. При наведении мышью выбирается именно объект под курсором, если он в пределах досягаемости и доступен из текущего дома. При отсутствии наведения E использует ближайший доступный контейнер.
- Название, время и шум в подсказке относятся к выбранному контейнеру. Во время поиска рамка становится янтарной и остаётся на обыскиваемом объекте.
- ЛКМ начинает обыск. Повторный клик по доступному контейнеру прерывает поиск без получения вещей. Удержание кнопки не перезапускает действие. E и движение сохраняют прежнюю возможность прерывания.
- При зажатой ПКМ ЛКМ всегда служит для боя. Рамка хранения скрывается во время прицеливания. Во время удара или оглушения клик по контейнеру не начинает поиск и не ставит случайную атаку в очередь.
- Клик по уже обысканному контейнеру открывает именно его инвентарь. Перемещение курсора к соседнему ящику не меняет открытое содержимое. При выходе из досягаемости доступ к открытому хранилищу пропадает; соседний ящик автоматически не подставляется.
- Пауза и загрузка очищают выбор. Формат сохранений остаётся v8, чтение v1–v8 сохранено. Предметы, распределение находок и правила шума предыдущего этапа используются без новой схемы данных.

Рамка использует уже существующий шейдер подсказок боя. Дополнительные модели, материалы из интернета и звуки не приобретались. Попадание указателя проверяется по границам видимых частей контейнера, без добавления физических коллайдеров или нового поиска пути.

## Проверка

Проверки выполняются в настоящем Windows Player через Unity Input System. Локальная сцена отключает заражённых и использует отдельное временное сохранение. Проверяются выбор из двух близких контейнеров, поиск и отмена мышью, удержание кнопки, приоритет прицеливания, пауза, графические кнопки переноса, привязка инвентаря, загрузка, клавиша E и отмена движением.

## Ограничения

Выбор мышью добавлен для контейнеров. Двери, радио и прочие действия пока используют прежнее управление. Автоматического подхода к далёким объектам нет: сначала нужно подойти самому. Наведение проверяет ограничивающие объёмы частей модели, а не точные треугольники. Полный обзор всех возможных перекрытий декоративной мебелью не выполнен.

Игра остаётся свободным выживанием; полное прохождение маршрута не используется как обязательная проверка. Производительность численно не измерялась. Новый Android APK не собирался; сенсорная проверка на устройстве не проводилась. GitHub не обновлялся.
