## Запуск

Локальная Windows-сборка находится рядом с проектом в `Zonbee-Infected`; архив — `Zonbee-Windows.zip`. Распакуйте целиком и запустите **Zonbee.exe**. Готовая версия этого этапа пока не публикуется на GitHub.

WASD — движение, Shift — бег, Ctrl — тихий шаг. ЛКМ — удар или обыск, ПКМ — направление удара, Пробел — толчок. E — действие, C у открытого окна — перелезть, V у задней двери — баррикада. F — фонарь, G — камень. I — вещи, J — навыки и ремесло, M — карта, F1 — справка, F11 — режим окна, Esc — пауза.

## Проект и сборка

Unity **6000.3.4f1**, Windows Build Support. Откройте этот каталог как существующий проект. Сцена — `Assets/Scenes/District.unity`. Для пары диагностической и обычной сборок задайте `ASKICH_BUILD_DIR` и `GOIDA_SURVIVAL_RELEASE` — два разных каталога — и вызовите метод `Askich.Editor.BuildDistrict.Pair` через Unity batchmode. Старые имена переменных и пространства Askich сохранены для совместимости инструментов. Исходники текущей игры не нужно переносить в другой проект.

Сохранения v1–9 загружаются, текущий формат — v9. При переименовании предусмотрен перенос профиля «Бережки»; подробности в отчёте этапа. Android пока отложен, проверка на устройстве для этой версии не проводилась.

Источники моделей, звуков и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md). История прежней средневековой GOIDA остаётся в git и старых документах; текущая игра — Zonbee.
